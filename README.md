⚽ Football Manager System

A console-based Football Manager simulation system written in Java.
This project allows managing players, teams, and transfer contracts.

------------------------------------------------------------------------

🚀 Features

✔ Player management
✔ Team management
✔ Transfer system
✔ Contract system (Permanent & Rented)
✔ Team size limit (max 22 players)
✔ Market value tracking
✔ Console-based interactive menu

------------------------------------------------------------------------

🧩 Project Structure

FootballProject/ │ 
├── Contract.java
├── Player.java
├── Team.java 
├── TransferBoard.java
└── SimulateSystem.java

------------------------------------------------------------------------

▶️ How to Run

1.  Open the project in any Java IDE
2.  Run: SimulateSystem.java

------------------------------------------------------------------------

🎮 Menu System

[1] List all Players in the system 
[2] List all Teams in the system 
[3] List all teamless players 
[4] Establish a contract 
[5] Terminate contract 
[6] Exit

------------------------------------------------------------------------

⚙️ System Logic

-   Each player can belong to only one team
-   Teams have a maximum capacity of 22 players
-   Contracts can be:
    -   Permanent
    -   Rented
-   Transfers update:
    -   Team size
    -   Team total value
-   Invalid operations are prevented by rules
